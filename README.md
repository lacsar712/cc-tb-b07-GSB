# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

若干子批可钉成**母批报告**（顶栏"母批报告"进入专页）。母批页展示子批名单、各子批最新加权分，以及服务端按最新分实时计算的母批均分；子批新交一轮审评后重开母批页即可看到新值。剔除子批为软删除，原钉入/剔除记录留在履历中。审评员（taster）可钉母批、追加钉入、剔子批；观察员（observer）只能看母批页与履历，写操作服务端一律返回 403。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 顶栏进入母批报告专页：taster 把春茶甲与春芽钉成母批，母批均分等于两批最新加权分的平均。
5. 春芽再交一轮更高分后重开母批页，春芽最新分与母批均分同步上升。
6. 剔除子批后名单与均分更新，履历中保留钉入与剔除记录；observer 能看母批页与履历，但钉母批、追加钉入、剔子批均返回 403。
