# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

若干子批可钉成母批报告：母批页展示子批名单、各子批最新加权分，以及服务端实时计算的母批均分（在册各子批最新加权分的平均）。子批新交一轮审评后重开母批页即看到新值。剔除子批只追加 remove 事件、不删历史，履历完整保留；被剔除的子批可再次钉入。

这是制茶审评，不是菜谱，也不是饮食记录。


## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 顶栏进入「母批报告」，新建母批并把「春茶甲」与「春芽」钉入：均分 = (8.0 + 7.0) / 2 = 7.5。
5. 回到审评记录页给「春芽」再交一组高分（如香气 9、滋味 9、汤色 9 → 加权 9.0），重开母批页：均分升至 8.5。
6. 剔除任一子批后，履历中同时保留钉入与剔除记录；重新钉入则再追加一条钉入记录。
7. observer 能打开母批页与履历，但看不到新建母批、钉入/剔除表单；直接 POST 写接口返回 403。
